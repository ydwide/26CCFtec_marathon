# 产品图大模型识别与电商搜索查价需求更新

## 更新背景

本次需求将 AI 定价链路从“用户填写物品信息后查价”调整为“用户提交产品图后，由大模型识别，再通过电商搜索/查价 skill 查找参考样本，给出大致价格”。

## 新需求口径

第一阶段默认链路调整为：

`用户提交产品图 -> 大模型识别物品 -> 输出品牌/物品名称/属性 -> 电商搜索 skill 查询参考样本 -> 计算市场均价 -> 结合成色给出大致价格 -> 后台人工复核`

## 输入与输出

### 用户输入

- 产品图：第一优先级输入。
- 物品名称：辅助输入，可为空或粗略填写。
- 成色：用于折算建议价格。
- 补充说明：用于帮助大模型识别。

### 大模型识别输出

- 品牌。
- 物品名称。
- 属性：例如型号、年代、材质、册数、颜色、适龄等。
- 建议类目。
- 建议标题。
- 建议描述。

### 电商搜索/查价 skill 输出

- 查价关键词。
- 平台参考样本。
- 样本价格。
- 价格区间。
- 市场均价。
- 定价理由。

## 定价原则

- 只给“大致价格/建议价”，不承诺真实成交价。
- 价格必须可人工复核。
- 样本不足或接口不可用时，必须提示人工复核，并保留演示 fallback。
- 后台审核页必须展示查价依据，不能只展示一个孤立价格。

## 当前实现落点

- 小程序捐赠提交接口支持 `imageUrls`。
- 后端新增产品图大模型识别适配器，可通过 `VISION_MODEL_API_URL` 替换真实模型服务。
- 后端电商查价适配器支持 `searchSkill: "commerce-market-search"` 与产品图来源信息，可通过 `MARKET_PRICE_API_URL` 替换真实电商搜索服务。
- 当前无真实第三方账号时继续使用 mock/fallback，保证第一阶段演示不断链。

## 后续接真实接口时需要补齐

- 图片上传存储：把本地/小程序图片上传成可被模型访问的 URL。
- 大模型视觉识别服务：明确请求格式、鉴权、返回字段和失败重试。
- 电商搜索 skill：明确可访问的平台、搜索策略、样本过滤规则和风控边界。
- 定价解释：把样本均价、成色折算、人工复核提示展示得更清楚。

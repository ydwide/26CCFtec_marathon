# 三端 UI 总规范

## 项目定位

本项目是 CCF 2026 技术公益马拉松 Track 3 的公益二手流通平台，覆盖：

- 微信小程序端
- App 端
- 后台管理端

核心目标是通过 `AI 辅助上架整理`，降低捐赠门槛、提升后台效率、增强公益流转透明度。

## 品牌规范

- 中文主品牌：`有温度的物命策展人`
- 英文副标：`Conscious Curator`
- 面向用户的标题、按钮、导航、状态与说明文案统一使用中文
- 英文仅作为副标或装饰，不作为主业务文案

## 视觉关键词

- 温暖
- 可信
- 公益
- 可持续
- 轻策展感
- 有品质感

## 色彩规范

- 主色：深绿色
- 强调色：暖橙色
- 背景色：浅米绿色
- 中性色：浅灰绿卡片体系

## 字体规范

- 标题：`Epilogue`
- 正文：`Manrope`
- 标签：`Plus Jakarta Sans`

## 三端定位

### 微信小程序端

- 轻入口
- 快速捐赠
- 商品浏览购买
- 流转进度查询

### App 端

- 深运营
- 消息触达
- 公益档案
- 长期参与关系沉淀

### 后台管理端

- AI 效率中枢
- 捐赠审核中枢
- 商品上架中枢
- 数据看板中枢

## 三端核心流程

`轻提交 -> AI 整理 -> 人工审核 -> 上架流通 -> 购买完成 -> 公益去向可追踪`

## 设计说明

本次上传的页面是比赛答辩与后续开发共用的“确定版关键页面”，优先强调：

- 公益流转
- AI 辅助整理
- 透明可信
- 三端分工清晰

后续如继续扩展页面，应保持本规范中的品牌、导航、色彩、组件与文案体系一致。

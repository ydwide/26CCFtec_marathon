# 红羊资料对齐：AI 智能入库与电商图搜查价

## 资料结论

本次补充的两份 PDF 与截图确认了第一阶段的产品方向：红羊美好商店需要用 AI 降低非标捐赠物资入库、命名、定价和上架门槛，而不是做一个单纯展示型商城。

其中系统需求 PDF 明确提出：

- 人工录入：拍照物品、输入数量。
- AI 商品定价：利用电商平台 API，通过图像识别查询商品价格，结合 AI 算法给出合理定价。
- 自动化入库：通过 AI 自动补充物品名称、商品主图，并打印条形码。
- 碳积分计算：根据入库物资清单自动计算碳减排总量。

红羊美好商店路演 PDF 的 AI 智能入库页进一步确认目标：用 AI 技术降低工作门槛，将非标捐赠物资快速转化为标准化数字商品。

## 第一阶段流程映射

线下旅途图需要映射到系统链路：

`扫码登录 -> 扫入库二维码 -> 拍清晰物品图 -> 填数量和捐赠方 -> 提交录入信息 -> 打印入库二维码 -> 贴码到物品上 -> 等 AI 补全 -> 扫码查看 AI 信息 -> 微调 AI 信息 -> 确认 AI 信息 -> 打印商品条码 -> 贴条码到物品上`

第一阶段系统实现口径：

`产品图提交 -> 大模型识别 -> 品牌/物品名称/属性补全 -> 电商图搜/查价 skill -> 市场均价与价格区间 -> 成色折算建议价 -> 后台人工微调确认 -> 入库二维码/商品条码展示`

## 真实接口方向

截图中的 OneBound `taobao.item_search_img` 文档可以作为后续真实电商图搜方向：

- 先把产品图转成平台可访问图片 URL，或按接口要求上传得到图片标识。
- 调用按图搜索接口获取淘宝/电商参考商品。
- 抽取标题、价格、图片、链接和平台来源作为样本。
- 过滤不相关样本和异常价格，再计算市场均价、价格区间和建议价。

当前第一阶段继续保留 mock/fallback，避免比赛演示时被第三方账号、网络或风控卡住。

## 阶段边界

第一阶段必须落地：

- 产品图是 AI 上架第一入口。
- 大模型输出 `品牌 - 物品名称 - 属性`。
- 电商搜索/查价 skill 输出样本、均价、价格区间和定价理由。
- 后台人工可以微调并确认上架。
- 审核台能展示入库二维码和商品条码，表达红羊线下“拍照贴码 -> AI 补全 -> 打印条码”的工作流。

第二阶段再扩展：

- 碳积分计算和证书。
- 小红花、会员、志愿者积分。
- 自助收银台硬件/软件联动。
- 完整线上商城、积分兑换和长期运营。
